# カラオケ補助ツール

Android・iPhoneのブラウザで使えるカラオケ補助Webアプリです。

## 使える機能

### 126BPMライト
- スマホ2台を顔の左右に置いて使います
- 各スマホで「左」「右」を選択
- それぞれの画面を曲の同じ拍でタップして同期
- 126BPM固定、画面全体が白と黒で1拍ごとに切り替わります
- ずれたら再タップで拍合わせできます
- オフラインで使用でき、端末間の通信は不要です

各端末の画面の明るさを手動で最大にしてください。

## 使い方
公開後、以下のURLをLINEで共有するだけです。

https://nao70161994.github.io/karaoke-helper/

初回はネット接続が必要です。一度ページをオンラインで読み込むと、以降オフラインでも利用できる構成です（保存状態はブラウザに依存します）。

## 公開設定
GitHubリポジトリの Settings → Pages → Build and deployment → Source から **GitHub Actions** を選択します。以後、mainブランチの更新で自動デプロイされます。

## 開発・テスト
- 外部JavaScriptライブラリ不要の静的Webアプリ
- `npm test`（Node.js 20以降）
- ローカル起動：`python3 -m http.server 8080`
- ファイル構成：`index.html`（ホーム）、`light.html`（照明）、`assets/`（CSS）、`src/`（照明ロジックとSW登録）、`tests/`（単体テスト）
- `.github/workflows/pages.yml` にデプロイワークフロー

## 動作上の制約
- カラオケ音声の自動認識ではなく、**タップで拍を合わせる方式**です
- 2台は互いに通信しません
- ブラウザからスマホ本体の画面輝度を上げることはできません
- iPhone Safariの全画面表示やスリープ抑止は端末・環境によって制限があります

今後、カラオケ補助機能をホーム画面に追加できます。
